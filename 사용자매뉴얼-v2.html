1시작하기

준비물

  • project-calendar-app-v2.html 파일 하나. 설치나 인터넷 연결은 필요 없습니다.
  • 최신 브라우저 (Chrome 또는 Edge 권장).

처음 실행

  1. 파일을 원하는 폴더에 복사하고 더블클릭해 브라우저로 엽니다.
  2. 처음 열면 "이 기기는 어디인가요?" 창이 뜹니다. 폐쇄망 PC라면 내부 (폐쇄망), 인터넷 PC라면 외부를 누르세요.
  3. 화면 왼쪽 위 배지에 "이 기기: 내부"(초록) 또는 "이 기기: 외부"(주황)가 보이면 준비가 끝난 것입니다.
데이터는 "그 PC의 그 브라우저" 안에만 저장됩니다.
· 같은 PC, 같은 브라우저로 다시 열면 데이터가 그대로 있습니다.
· 다른 브라우저(Chrome ↔ Edge)나 다른 PC에서 열면 빈 화면이 나옵니다. 이때는 동기화나 백업 복원으로 데이터를 옮기세요.
· 브라우저의 "인터넷 사용 기록 삭제"에서 쿠키 및 사이트 데이터를 지우면 데이터도 함께 지워집니다. 정기적으로 전체 백업을 해 두세요.

2v1에서 v2로 바꾸기

기존 v1 파일을 쓰고 있었다면 아래 순서로 바꾸세요.

  1. 먼저 백업: v1 파일을 열고 ⚙ 설정 → ⬇ 전체 백업(JSON)을 눌러 백업 파일을 저장합니다.
  2. v2 파일을 v1 파일과 같은 폴더에 두고, 같은 브라우저로 엽니다. 기존 일정과 회의록이 그대로 보이면 끝입니다.
  3. 데이터가 안 보이면 v2에서 ⚙ 설정 → ⬆ 백업 복원으로 1번의 백업 파일을 여세요.
  4. 내부 PC와 외부 PC 모두 v2로 바꿉니다. 폐쇄망 PC로 파일을 옮길 때는 평소 반입 절차를 따르세요.
두 PC를 모두 v2로 바꿔야 합니다. 한쪽만 v1이면 취소·연기·회의록 연결·액션아이템 정보가 그쪽으로 넘어가지 않습니다. v2에서 v1 패치를 가져오면 미리보기에 "구버전(v1) 앱에서 보낸 패치" 경고가 뜹니다. 이때 이 PC에 있던 v2 정보는 지워지지 않고 그대로 유지됩니다.

v2에서 바뀐 점

기능내용
일정 취소 NEW열리지 않은 회의를 지우지 않고 취소선으로 남깁니다. 취소 사유도 적을 수 있습니다.
일정 연기 NEW날짜나 시간을 바꾸면 원래 자리에 취소선 + "→ 새 날짜"가 남습니다.
일정 ↔ 회의록 연결 NEW일정에서 바로 회의록을 만들면 일자·시간·주제가 자동으로 채워집니다. 회의록이 있는 일정에는 달력에 📝가 붙습니다.
액션아이템 NEW회의록마다 할 일·담당자·기한을 적고, ✅ 할 일 탭에서 모아 보며 완료 체크를 합니다.
보안 수정제목에 작은따옴표(')가 들어가면 화면이 깨지던 문제와, 조작된 패치 파일로 스크립트가 실행될 수 있던 문제를 고쳤습니다.
엑셀(CSV)일정 파일에 상태(진행/종료/취소)·취소 사유·원래 일정 열이 추가되고, 액션아이템 CSV가 따로 저장됩니다.

탭하는 일
📅 달력월 단위 일정 보기, 추가, 수정. 휴대폰처럼 좁은 화면에서는 날짜를 누르면 아래에 그날의 일정 목록이 나옵니다.
📝 회의록회의록 목록(최신순)과 검색. 확인 사항 아래에 액션아이템 요약이 보입니다.
✅ 할 일 NEW모든 회의록의 액션아이템 모아보기. 탭 이름 옆 숫자는 미완료 건수입니다.
🔄 동기화다른 PC로 내보내기(QR·파일)와 다른 PC에서 가져오기.
⚙ 설정화면 디자인(테마), 기기 이름, 백업·복원, 엑셀 내보내기, 전체 삭제.

위쪽 배지에는 이 기기 이름과 마지막 동기화 시각이, 아래쪽 바에는 일정·회의록 건수가 표시됩니다.

4일정 관리 (달력)

일정 추가

  1. 달력에서 날짜 칸의 빈 곳을 클릭합니다. 휴대폰에서는 날짜를 누른 뒤 + 일정 추가를 누릅니다.
  2. 날짜, 제목, 시작·종료 시간(30분 단위, 비우면 종일), 메모, 막대 색상을 입력합니다.
  3. 저장을 누릅니다.

일정 수정·상태 바꾸기

달력의 일정 막대를 클릭하면 수정 창이 열립니다. 창 아래쪽 버튼은 다음과 같습니다.

버튼용도
✔ 종료 처리실제로 진행된 일정을 완료로 표시합니다 (✔ + 흐린 취소선).
✕ 취소 처리 NEW열리지 않게 된 일정. 5장을 보세요.
삭제잘못 입력한 일정. 화면에서 완전히 사라집니다.
📝 회의록 작성/열기 NEW이 일정과 연결된 회의록을 만들거나 엽니다. 6장을 보세요.

그 밖의 기능

  • ✔ 지난 일정 종료: 시간이 지난 일정을 한 번에 종료 처리합니다. 취소된 일정은 건드리지 않습니다.
  • ◀ ▶ 오늘: 달을 이동합니다. 터치 화면에서는 달력을 좌우로 밀어도 됩니다.
  • 한 칸에 일정이 많으면 +N으로 접힙니다. 창을 키우면 더 많이 보입니다.

5취소와 연기 NEW

삭제, 취소, 종료는 언제 쓰나요?

구분언제화면
종료회의가 실제로 열렸을 때✔ + 흐린 취소선
취소잡혀 있던 회의가 없어졌을 때✕ + 취소선 + 회색. 기록이 남습니다
연기다른 날짜나 시간으로 옮겨졌을 때원래 자리에 취소선, 새 자리에 ↪
삭제잘못 입력했을 때완전히 사라짐

일정 취소하기

  1. 달력에서 일정 막대를 클릭합니다.
  2. ✕ 취소 처리를 누릅니다.
  3. 취소 사유를 입력합니다 (예: "고객사 일정 변경"). 비워도 되고, 입력 창에서 취소를 누르면 아무것도 바뀌지 않습니다.
  4. 연결된 회의록이 있으면 "회의록도 '취소된 회의'로 표시할까요?"라고 묻습니다. 보통 확인을 누르세요.

되돌리려면 같은 창에서 ↺ 취소 해제를 누릅니다.

일정 연기하기

  1. 일정 막대를 클릭합니다.
  2. 날짜나 시작 시간을 새 값으로 바꿉니다.
  3. "날짜·시작 시간을 바꾸면 연기로 기록"에 체크된 상태(기본값)로 저장을 누릅니다.
11/25 14:00 리뷰 회의→ 날짜를 11/27로 변경 →11/25: 14:00 리뷰 회의 → 11/2711/27: ↪ 14:00 리뷰 회의
  • 단순한 입력 실수를 고치는 경우라면 체크를 해제하고 저장하세요. 연기로 기록되지 않습니다.
  • 원래 날짜와 시간으로 다시 돌려놓으면 연기 표시가 자동으로 사라집니다.
  • 연기 표시만 지우고 싶다면 수정 창 위쪽의 연기 표시 지우기를 누르세요.
  • 두 번 이상 연기하면 바로 직전 일정이 "원래 일정"으로 기록됩니다.

6회의록 작성

방법 ① 일정에서 바로 만들기 (권장) NEW

  1. 달력에서 회의 일정을 클릭합니다.
  2. 📝 회의록 작성을 누르면 일자·시간·주제가 채워지고 일정과 연결된 회의록 창이 열립니다.
  3. 확인 사항, 액션아이템, 비고를 입력하고 저장을 누릅니다.

저장하면 달력의 그 일정에 📝가 붙고, 회의록 목록의 주제 옆에는 🔗가 붙습니다. 다음에 같은 일정을 열면 버튼이 📝 회의록 열기로 바뀝니다.

방법 ② 회의록 탭에서 만들기

  1. 📝 회의록 탭에서 + 회의 추가를 누릅니다.
  2. 일자를 고르면 연결된 일정 목록에 그날의 일정이 나옵니다. 하나를 고르면 연결되고, 주제나 시간이 비어 있으면 일정 내용으로 채워집니다.

입력 항목

항목설명
일자 / 시간시간은 자유롭게 입력합니다 (예: 14:00~16:00).
연결된 일정 NEW달력 일정과 연결합니다. "(연결 안 함)"을 고르면 연결이 풀립니다.
주제필수입니다.
확인 사항 / 결정 사항회의 내용과 결정된 사항을 자유롭게 적습니다.
액션아이템 NEW7장을 보세요.
취소된 회의 NEW체크하면 목록에 취소선으로 표시되고, 액션아이템 모아보기에서 빠집니다.

검색

회의록 탭의 검색 칸은 주제, 확인 사항, 비고, 액션아이템 내용, 담당자를 모두 찾습니다.

7액션아이템 (할 일) NEW

회의록에서 추가하기

  1. 회의록 창에서 + 액션아이템 추가를 누릅니다.
  2. 한 줄에 할 일 · 담당자 · 기한을 입력합니다. 담당자 칸에는 전에 입력한 이름이 자동 완성으로 나옵니다.
  3. 필요한 만큼 추가하고 저장을 누릅니다. 줄 끝의 ✕는 그 항목을 지우고, 앞의 체크는 완료 표시입니다.
할 일 칸을 비운 줄은 저장할 때 자동으로 빠집니다.

✅ 할 일 탭에서 모아 보기

  • 취소되지 않은 모든 회의록의 액션아이템을 한곳에 보여줍니다.
  • 정렬 순서: 미완료 → 기한이 빠른 순 → 기한 없음.
  • 빨간 기한 (지남)은 기한이 지난 미완료 항목입니다.
  • 오른쪽 위에서 담당자와 미완료만 / 전체 / 완료만을 골라 볼 수 있습니다.
  • 체크박스를 누르면 바로 완료 처리됩니다. 📝 회의 이름을 누르면 그 회의록이 열립니다.
  • 회의록 탭에서도 확인 사항 아래에 ☐ 미완료 / ☑ 완료 요약이 보입니다.

8동기화: 외부 ↔ 내부

이 앱은 서버 없이 "변경분 묶음(패치)"을 직접 옮겨서 두 PC의 데이터를 맞춥니다. 방향마다 보내는 PC에서 내보내기 → 받는 PC에서 가져오기를 한 번씩 합니다.

외부 PC: 내보내기→ QR 사진 또는 패치 파일 →내부 PC: 가져오기
내부 PC: 내보내기→ QR 사진 또는 패치 파일 →외부 PC: 가져오기

8-1. 내보내기 (보내는 PC)

  1. 🔄 동기화 탭을 엽니다.
  2. 범위를 고릅니다.
    • 시작일 / 종료일: 기본값은 보고 있는 달부터 다음 달까지입니다. 기간=전체를 누르면 날짜 제한이 없어집니다.
    • 일정(달력) / 회의록: 보낼 종류를 고릅니다.
    • 마지막 전송 이후 변경분만 (기본 체크): 지난번 "전송 완료" 이후에 바뀐 것만 보냅니다. 처음 보낼 때나 전부 다시 보내려면 체크를 해제하세요.
  3. 아래의 "내보낼 내용: 일정 N건, 회의록 N건"을 확인합니다.
  4. 보내는 방법을 고릅니다 (아래 A 또는 B).

방법 A: 📷 QR로 내보내기 (USB나 이메일 반출이 어려울 때)

  1. 📷 QR로 내보내기를 누르면 QR이 한 장 이상 나옵니다. 장수는 데이터 양에 따라 달라집니다.
  2. 여러 장이면 한 장씩 크게 화면에서 → 키나 다음 ▶로 넘기며 휴대폰 카메라 앱으로 한 장씩 모두 찍습니다.
    • QR이 화면에 꽉 차게, 정면에서, 모니터 밝기를 높여 찍으세요.
    • 마우스 커서를 QR 밖으로 치우세요.
    • 이웃 QR이 같이 찍히지 않게 한 장씩 크게 띄우세요.
  3. 다 찍었으면 닫기를 누르고, "전송 완료로 표시할까요?" 질문에 답합니다 (8-4 참고).
  4. 찍은 사진을 받는 PC로 옮깁니다. 휴대폰을 PC에 USB로 연결하는 등 조직에서 허용된 방법을 쓰세요.

방법 B: 📄 파일로 내보내기 (이메일 반입·반출이 가능할 때)

  1. 📄 파일로 내보내기를 누르면 psync-외부-20261125_1430.json 같은 작은 파일이 저장됩니다.
  2. "전송 완료로 표시할까요?" 질문에 답합니다 (8-4 참고).
  3. 이 파일을 이메일 첨부 등 조직의 반입·반출 절차에 따라 상대 PC로 옮깁니다.
파일 방식이 가장 확실합니다. 데이터가 많아 QR이 10장을 넘으면 파일 방식을 권장합니다.

8-2. 가져오기 (받는 PC)

QR 사진으로 받을 때

  1. 🔄 동기화 → 🖼 QR 사진으로 가져오기를 누릅니다.
  2. 찍은 사진을 모두 한꺼번에 선택합니다 (Ctrl 또는 Shift를 누른 채 클릭).
  3. 분석이 끝나면 번호 칸이 나옵니다. 초록은 읽은 QR, 빨강은 못 읽은 QR입니다.
  4. 못 읽은 번호가 있으면 보내는 PC에서 그 번호만 다시 찍어 🖼 사진 더 추가로 선택합니다. 이미 읽은 번호는 그대로 유지됩니다.
  5. 모든 번호를 읽으면 자동으로 가져오기 미리보기가 열립니다.

패치 파일로 받을 때

  1. 🔄 동기화 → 📄 패치 파일 열기를 누르고 받은 .json 파일을 고릅니다.
  2. 바로 가져오기 미리보기가 열립니다.

취소, 연기, 회의록 연결, 액션아이템도 모두 함께 동기화됩니다. 미리보기 문구에서는 [취소], [연기: 원래 일정→], 액션아이템 N건으로 표시됩니다. 액션아이템은 회의록 단위로 넘어가므로, 한 회의록의 액션아이템을 양쪽에서 동시에 고치면 양쪽수정으로 나옵니다.

8-4. "전송 완료로 표시"란?

내보내기가 끝나면 "이 변경분을 '전송 완료'로 표시할까요?"라고 묻습니다.

  • 확인 (예): 다음에 "변경분만" 내보낼 때 지금 이후에 바뀐 것만 담깁니다. 상대 PC가 잘 받은 것이 확실할 때 누르세요.
  • 취소 (아니오): 기준 시각을 그대로 둡니다. 같은 내용을 다시 보낼 수 있습니다. 상대가 아직 못 받았거나 확실하지 않을 때 누르세요.
"전송 완료"를 눌렀는데 상대가 못 받았다면, "마지막 전송 이후 변경분만" 체크를 해제하고 기간을 넉넉히 잡아 다시 내보내세요. 이미 받은 항목은 미리보기에 동일로 나와 자동으로 빠지므로 중복될 걱정은 없습니다.

8-5. 권장 동기화 습관

  1. 한쪽에서 몰아서 작업하고, 작업을 마칠 때 상대 PC로 내보내기를 원칙으로 합니다.
  2. 상대 PC에서 작업을 시작하기 전에 받은 패치를 먼저 가져옵니다. 그래야 양쪽수정이 거의 생기지 않습니다.
  3. 양방향으로 맞출 때는 외부 → 내부를 먼저 적용한 뒤, 내부에서 내부 → 외부로 내보냅니다.
  4. 두 PC의 시계(날짜·시각)가 맞는지 가끔 확인하세요. 어느 쪽이 최신인지 수정 시각으로 판단하기 때문입니다.
  5. 한 달에 한 번 정도는 양쪽 모두 전체 백업을 해 두세요.

9백업·복원·엑셀

버튼 (⚙ 설정)설명
⬇ 엑셀(CSV) 내보내기일정·회의록·액션아이템 CSV 파일 3개를 저장합니다. 엑셀에서 바로 열 수 있습니다. 브라우저가 "여러 파일 다운로드 허용"을 물으면 허용하세요.
⬇ 전체 백업(JSON)이 PC의 모든 데이터를 파일 하나로 저장합니다.
⬆ 백업 복원백업 파일로 현재 데이터를 통째로 바꿉니다. 합치는 것이 아니라 교체입니다.
전체 데이터 삭제이 PC의 일정과 회의록을 모두 지웁니다. 되돌릴 수 없으니 먼저 백업하세요.
백업 복원은 "이 PC를 그 시점으로 되돌리기"입니다. 두 PC의 데이터를 합치려면 복원이 아니라 동기화를 쓰세요.

10설정

  • 화면 디자인: 미드나잇, 화이트, 파스텔, 포레스트, 클래식 종이, 고대비 중에서 고릅니다. 이 브라우저에만 적용되고 동기화와는 관계없습니다.
  • 기기 이름: 내부, 외부, 직접 입력 중에서 고릅니다. 동기화 미리보기에 "보낸 기기"로 표시되니 두 PC를 서로 다른 이름으로 지정하세요.
  • 기기 ID: 자동으로 만들어지며 바꿀 필요가 없습니다.

11자주 묻는 질문·문제 해결

Q. 파일을 다시 열었더니 데이터가 없어요.
다른 브라우저로 열었거나, 브라우저 데이터가 지워졌을 수 있습니다. 평소 쓰던 브라우저로 다시 열어 보고, 그래도 없으면 백업 복원을 하세요.
Q. QR 사진에서 QR을 못 찾는다고 나와요.
QR이 사진에 꽉 차게, 정면에서, 초점이 맞게 다시 찍으세요. 모니터 밝기를 최대로 하고 반사를 피하세요. 그래도 안 되면 파일로 내보내기를 쓰세요.
Q. "다른 내보내기 QR"이라고 나와요.
서로 다른 내보내기에서 나온 QR 사진이 섞였습니다. 이번 내보내기 화면의 QR만 다시 찍어 처음부터 가져오세요.
Q. 내보낼 변경 내용이 없다고 나와요.
"마지막 전송 이후 변경분만"이 체크되어 있고 그 이후 바뀐 게 없는 경우입니다. 다시 보내려면 체크를 해제하세요.
Q. 미리보기에 "구버전(v1) 앱에서 보낸 패치"라는 경고가 떠요.
보낸 PC가 아직 v1 파일을 쓰고 있습니다. 적용해도 이 PC의 취소·연기·액션아이템 정보는 지워지지 않지만, 상대 PC도 v2로 바꿔 주세요 (2장).
Q. 취소한 일정을 완전히 지우고 싶어요.
일정을 열고 삭제를 누르세요. 삭제한 사실도 동기화로 상대 PC에 전달됩니다.
Q. 연기한 일정의 원래 자리 표시를 없애고 싶어요.
일정을 열고 위쪽의 연기 표시 지우기를 누르세요.
Q. 일정을 지웠더니 회의록의 🔗가 사라졌어요.
연결된 일정이 삭제되면 회의록의 연결 표시만 사라지고, 회의록 내용은 그대로 남습니다.
